- **Surprise**: **The injection strategy that protects the user's privacy is the one that corrupts their words.** §7.3 offers `strategy = "keystroke"` to users who cannot accept the clipboard exposure and prices it as "slower and more failure-prone". Measured, it is neither of those things first — it is *lossy*. macOS text substitution applies to synthetic keystrokes exactly as it does to real ones: `don't use --dashes... "quoted" and i said so` arrives in TextEdit as `don't use —dashes… "quoted" and I said so`. Five changes in one sentence, and pasting the identical string is byte-identical. Nothing in the application can reach another application's substitution settings, so it cannot be fixed — only warned about. It also disqualifies `keystroke` as a *silent* automatic fallback when clipboard injection fails, which is exactly how a fallback wants to be written. The finding came from reading TextEdit's own document text; the Accessibility read-back could not see it, because it reads the raw injected value before the substitution settles. An instrument that verifies **arrival** does not verify **fidelity**, and I nearly recorded a clean four-application PASS without noticing the difference.
- **Proposal**: For GOTCHAS — **a null result and a negative result both need a positive control, and the control has to be per-instrument.** Phase 1 learned this for null results; Phase 2a needed it in the other direction twice on the same day. The clipboard-exposure measurement first reported "transcript NOT captured by the manager", which would have published a false all-clear on the most-argued privacy surface in the PRD; it was wrong because the read ran before the manager flushed, and it was caught only because a control copy was added afterwards and came back captured. The gate harness separately reported a **native-field FAIL** — the single most consequential verdict it can return, and the one §9 rejects the phase on — for a settle window too short to see a 22-character keystroke marker land. Three of the harness's first four verdicts about the product were wrong, and every one of them was the instrument. **Before believing any gate verdict, ask what would have to be true for the instrument to produce it by accident.** A gate that fails by measuring nothing is the same bug as one that passes by measuring nothing; this repo now has instances of both.
